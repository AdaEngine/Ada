Production additions:

- AdaAssets ProceduralRig and GLBWriter: skin influences, inverse binds and animation
  export/validation. Preserve mesh space for skinning.
- AdaScriptModelGenerator: additive model-builder functions.
- AdaScriptModelRigBuilder: generic bounded storage, model-space baking,
  rigid/two-joint weights, translation/rotation tracks and material merging.
  Character anatomy and motion rules remain in AdaScript.
- AdaScriptGeneratorDelegate: module loading and diagnostics without ECS/scene
  bindings; used by the existing isolated generator runner.
- Editor tool descriptions and bundled skills document the new API. No new MCP
  endpoint or parameters are required.

Builder functions ship as precompiled native app code. The embedded compiler
produces bytecode interpreted by the VM; recipes need no machine-code generation,
JIT, Swift compiler, Python or process spawning. Rendering and skeletal playback
use the existing runtime.

Validation uses actual production sources in an isolated package with a standalone
resource-scope adapter. Installed Studio predates the bridge extension: it proves
playback of the output, not new MCP generation. An updated application bundle and
physical iPad validation remain separate work.

Scene units are meters, Y is up, and the character faces −Z. The recipe knows the
names/hierarchy of generated parts; this is explicit procedural rigging, not
anatomy inference or an imported-mesh weight editor.
