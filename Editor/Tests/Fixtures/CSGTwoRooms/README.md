# Two-room CSG project

Copy this directory to a writable location and open it in desktop Ada Studio.
The scene starts with **Doorway** selected. Change its operation from
**Difference** to **Union** to close the opening, then use **Undo** to restore
the cut. Use **Play** to see the current result through the scene camera.

The group joins the walls, cuts the doorway, and adds the floor last to keep
it flush with the opening. The game3d project enables Physics 3D for the
generated static collider. The fixture includes a camera and a light.
