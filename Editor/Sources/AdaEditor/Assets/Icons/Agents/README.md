# Agent logos

Official SVG logos from the [ACP Registry](https://github.com/agentclientprotocol/registry), retrieved 2026-10-09. `Sources.json` records each source URL and SVG SHA-256.

The PNG files are 64 x 64 transparent white masks, rasterized with macOS AppKit for AdaUI template tinting. They keep common agents recognizable without a network request. Sloppy uses the existing `../sloppy_logo.png` asset.
