# External Asset Library for Ada Studio

Status — Proposed for approval

## Scope

Ship an optional desktop Studio Tools plugin as a separate Ada Asset Store listing. It gives each project a gallery of saved Unity Asset Store and Fab assets with thumbnail previews, title search, store filters, local file management, and Ada AI search. The first release targets native Ada Studio on Windows and macOS, with English and Russian UI. The library is the first consumer of the [shared plugin intents and tools contract](studio-plugin-ai-capabilities.md).

Full catalog search and in-Studio downloads depend on provider access. The first release proposal uses the stores' user-facing download flows and brings the resulting files into Studio. The table distinguishes the first release from an authorized live integration.

| Action | First release | With authorized provider access |
| --- | --- | --- |
| Browse and search | Browse saved listings, search their titles and filter by All, Fab or Unity Asset Store. Open either store to find new listings, then save a listing URL and enter a title in Studio. | Show live results from each provider that grants catalog access, with supported format and license information where available. |
| Preview | Show an optional user-supplied cover before the model is available. Generate a thumbnail and offer an interactive 3D preview once a compatible local model is attached. | Show licensed provider thumbnails for live results when provider access also covers preview media. |
| Get a file | Open the listing for purchase or download. Fab supports download and export to a local folder from its launcher. Unity supplies downloads via Package Manager. In Studio, select the compatible file from disk. | Download entitled files into the plugin's project library using the provider's supported flow and the user's account. |
| Search with Ada AI | Use the search intent to find saved assets by title and store. Use the asset details tool to look up a returned asset. Both require the project's AI grant. | Query a live catalog within the access and metadata permissions the provider grants for AI-assisted search. |
| Remove a local copy | Confirm removal in Studio. Keep the saved listing available for later use. | Use the same local removal flow for files downloaded through an authorized provider. |

Unity's Asset Store terms restrict automated access and require a separate agreement for access outside Unity's interface. Its general terms also specify authorization for third-party integrations and agentic access. Fab documents Custom Disk Location and Custom Socket Port export in its launcher. Those export features operate on files obtained through Fab. No documented public Fab catalog and authenticated download API suitable for this plugin was identified. Fab Standard-licensed assets can be used in compatible tools subject to the asset's terms. Check the applicable license and format for each asset before using it in Ada Studio. [Unity Asset Store terms](https://unity.com/legal/as-terms), [Unity Terms of Service](https://unity.com/legal/terms-of-service), [Unity Asset Store download workflow](https://docs.unity3d.com/Manual/AssetPackages.html), [Fab launcher export workflow](https://dev.epicgames.com/documentation/fab/exporting-assets-from-fab-in-launcher), [Fab licenses](https://www.fab.com/eula).

## GodotFab reference

GodotFab mounts a main editor tab with a responsive thumbnail grid, filters and asset details. Its search view debounces changes, pages results as the user scrolls, and ignores responses from an older search. It queues thumbnail loads and keeps disk and memory caches. Its download jobs track each asset separately, support resume, and allow the user to delete acquired download data without removing imported assets. Adopt these interaction and lifecycle patterns for Ada Studio. [Gallery](https://github.com/alextrevisan/GodotFab/blob/c20ecb460a8fc960319c0ca43eaa8878f5b8deaf/addons/godotfab/ui/gallery.gd), [search](https://github.com/alextrevisan/GodotFab/blob/c20ecb460a8fc960319c0ca43eaa8878f5b8deaf/addons/godotfab/ui/search_view.gd), [thumbnails](https://github.com/alextrevisan/GodotFab/blob/c20ecb460a8fc960319c0ca43eaa8878f5b8deaf/addons/godotfab/ui/thumbnails.gd), [jobs](https://github.com/alextrevisan/GodotFab/blob/c20ecb460a8fc960319c0ca43eaa8878f5b8deaf/addons/godotfab/jobs.gd).

Its Fab adapter queries an undocumented catalog endpoint. Authenticated downloads use Epic Games Launcher credentials obtained through a manually pasted browser authorization code. It uses listing and library endpoints to obtain signed download information and fetches payloads from Epic's CDN. The public repository documents this integration but does not establish provider authorization or stability. Ada Studio's release uses the official Fab browser and launcher flows. Keep any authorized live adapter behind the same library interfaces. [GodotFab integration overview](https://github.com/alextrevisan/GodotFab/blob/c20ecb460a8fc960319c0ca43eaa8878f5b8deaf/README.md#how-it-works).

## Studio workflow

1. Download the plugin ZIP from Ada Asset Store and install it for the open project through Studio Tools. Review access and enable it. Open the project's gallery in a workbench tab from Studio Tools.
2. Add a public listing URL and a title. An optional local PNG or JPEG can serve as a cover when the user has permission to use that image. Studio derives the store from the URL and opens that page in the system browser on request. Cards show a preview, title, store and local file status. Use a Material Symbol placeholder when no preview is available. An empty library offers both storefront links and a way to add a listing. Search matches titles case-insensitively, with a dropdown for the store and a distinct empty-results state. Saving the same listing twice reuses its existing entry.
3. Use **Open in store** to get the asset. For Fab, the user can export a GLB with the launcher’s documented custom disk destination, or download a compatible file directly if the listing offers it. For Unity, select a compatible file obtained through the user's standard Unity workflow. Studio accepts a self-contained GLB for the initial import and uses its existing model inspection and import path. Engine-specific packages require a compatible export from the appropriate tool. A missing or invalid file leaves the listing available and shows how to retry.
4. Use **Add local file** to copy the selected file into the project’s plugin-managed library. Preview that copy and use **Import into project** to make a separate project asset that can be placed in a scene. **Remove local copy** shows the file and asks for confirmation. It removes only the managed copy. Store entitlements, originals selected from disk, and files already imported into the project are preserved. Closing or switching projects cancels pending work and invalidates its UI results.

The [rendered proposal](assets/external-asset-library.png) shows a workbench tab with the gallery and selected asset details. Use the existing AdaUI theme, selection styles, labeled text field, dropdown and buttons. Adapt the column count to available space. At narrow widths open details in the same tab with a back action. Preserve selection when opening the browser and when the selected result still matches the filter. Hide detail actions when the selected listing is filtered out. Restore focus after the dropdown, details, dialogs and file picker. Use localized labels and errors.

Generate a still thumbnail from each attached GLB with a camera framed to model bounds. Reuse the model preview scene and completed-frame capture path. Only the selected item's details get an interactive viewport. Queue thumbnail work for visible results, decode images within byte and pixel budgets, and cache thumbnails by source revision and renderer version. A failed preview shows the placeholder without blocking search or import. Replacing or removing the managed model invalidates thumbnails generated from that model. A separately supplied cover survives model removal. Cancel outstanding preview work on project changes and ignore stale results.

## Ownership and access

- The Ada Asset Store listing contains the versioned plugin package. The current Store supports ZIP downloads. The project-local Studio Tools host owns discovery, consent, activation and revocation. Add a scoped install path and a versioned declarative contribution for the gallery tab and asset-library capability. The optional package activates this contribution. Ada Studio hosts the AdaUI views and typed file, browser and search operations. Keep provider access separate from the Store package and Studio runtime. Package installation must validate the layout and compatibility, reject escaping paths, symlinks and unsupported content, and leave an active installation intact on failure. Use the Store ZIP download from either desktop browser.
- Use one project-scoped library service for the panel and Ada AI. Store canonical source, listing identity, user-authored title, and references to plugin-owned files. Accept only HTTPS listing URLs on the supported storefronts and normalize browser-only query parameters away. Stage and validate files before publishing them, reject paths outside the managed directory, and serialize changes for the same listing. Reconcile an interrupted copy or removal at the next open. Disablement and uninstall withdraw access immediately. Users can re-enable the plugin and recover their saved library.
- Contribute the read-only search intent and asset details tool through the [shared contract](studio-plugin-ai-capabilities.md). Search takes a title query and optional store filter. It returns a bounded list of asset references with user-authored titles, stores and local availability. Details looks up a single reference. Keep credentials, local paths, file contents, listing descriptions and preview images out of tool results. Keep the gallery usable when the Cloud contract is unavailable.
- Keep provider permissions independent for browsing, metadata in AI search, and entitled downloads. Direct provider features require documented access or a provider agreement that covers the specific operation. Use provider-managed sign-in and entitlement checks when an authorized integration is available. Surface provider limitations on the corresponding action. Ada Store distributes the plugin package. The source store delivers its assets to each user under that user's license.

## Acceptance and documentation

1. On Windows and macOS, install a release-shaped ZIP via Studio Tools, review access, enable it, and reopen the project. Check absent, incompatible, invalid, disabled, revoked, and re-enabled packages. Verify that revocation hides the panel and removes the AI action even with a search in flight. Verify a release listing and its downloadable ZIP in Ada Asset Store before claiming distribution.
2. Save one real Fab listing and one Unity listing, filter each source, search by partial title with different casing, and handle duplicate URLs, invalid hosts and empty results. Open each listing through the native browser action. Exercise a real Fab launcher GLB export and a compatible model obtained through Unity's documented workflow where its license permits. Verify the placeholder, user-supplied cover, generated thumbnail, and rotatable 3D preview. Import the model and reopen the project. Confirm deletion preserves the downloaded original, supplied cover and imported project copy. Cover cancellation, malformed files, cache invalidation, interrupted updates, and project switching through production entry points.
3. In an enabled test project on a compatible Ada Cloud deployment, ask Ada AI to find a saved asset by title and store and look up its details. Verify authorized calls in Ask, Plan and Build. Test disabled AI access, project isolation, unsupported Cloud versions and revoked permissions, with no ability to import or remove files through the two read-only contributions.
4. Inspect the actual Studio gallery on both platforms in English and Russian with normal and narrow widths. Verify thumbnail loading and failure, grid and details layout, focus, dropdown selection, pointer and keyboard states, empty results, errors, disabled actions and confirmation. Record screenshots and run focused tests and the contribution checks.

Update the user-facing [Editor Guide](../../Editor/Documentation/EditorGuide.md) with an External Asset Library section, link it from [Studio Tools](../../Editor/Documentation/StudioTools.md), and document the AI opt-in in [Cloud AI](../../Editor/Documentation/CloudAI.md). Walk through adding a Fab listing, exporting its GLB, finding it with Ada AI, opening the preview, importing it, and removing the managed copy.
